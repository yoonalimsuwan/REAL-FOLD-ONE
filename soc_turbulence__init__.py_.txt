WHAT THIS PACKAGE IS
=============================================================================
A CONTROL LAYER, not a turbulence model and not a CFD solver.

Standard numerics (cited, not claimed as novel):
  Smagorinsky 1963, WALE (Nicoud-Ducros 1999), Vreman 2004,
  k-epsilon (Launder-Spalding 1974), k-omega SST (Menter 1994),
  Spalart-Allmaras 1992, Kolmogorov 1941 scaling.

Ours (the decision layer):
  [T1] CSOC event-count bound  N(T) <= (E_max + D)/delta_E_min
       with CORRECT dissipation accounting.
  [T2] kappa-fatness gate on refinement (delta_min isodiametric).
  [T3] Carpet rho >= 9/8 multi-scale graph energy as PRIORITY.
  [T4] OPMC design parameterisation — exact gradients via decoder.
  [T5] Hodge-INSPIRED split (NOT Hodge theory).
  [T6] Assumption-light CI (Politis-Romano subsampling).
  [T7] Kolmogorov resolution monitor — the DNS criterion.

See THEOREMS.md for statements, hypotheses, proofs, and NON-claims.

=============================================================================
HONEST SCOPE
=============================================================================
* DNS is a RESOLUTION statement: Delta <= c_eta * eta. Setting nu_t = 0
  on an under-resolved grid gives a WRONG under-resolved DNS, not DNS.
  dns_feasibility() reports "NOT ATTAINABLE" when N ~ Re^(9/4) exceeds
  budget. It does not hide this.
* k-epsilon / SST / SA need TRANSPORTED k, epsilon, omega, nuTilda.
  This package READS them from `state`. local_equilibrium_state() is a
  DEMO estimate, clearly labelled.
* SST without `d_wall` uses F2 = 1 (far-field limit). NOT valid for
  wall-bounded flow. Supply d_wall.
* No external validation. Analytic Taylor-Green only.
* The event bound is an ENGINEERING guarantee on the switching
  mechanism, of the same kind as a CFL bound. It is NOT a statement
  about Navier-Stokes regularity.
